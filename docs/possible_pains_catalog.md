# Каталог возможных управленческих болей

Справочник для формулировки поля «Управленческая боль» в UI и пакетных прогонов.  
Связан с матрицей `data/matrix_defects.txt` и типовыми кейсами в `images/image_pains.md`.

## Универсальные (любая отрасль)

- Хаос в управлении, нет ясных ролей и ответственности
- Ручное управление собственником, всё замыкается на нём
- Частая смена приоритетов, нет зафиксированных целей
- Низкая производительность при полном штате
- Финансовые / кассовые разрывы
- Рост оборота без роста прибыли
- Зависимость результата от отдельных «незаменимых» людей
- Много неэффективных совещаний, решения не доходят до исполнения
- Бардак в документообороте и передаче задач между отделами

## Маркетинг ↔ производство (поток)

- Недозагрузка производства / простои мощностей
- Перегруз производства, очереди, срывы сроков
- Нестабильный поток клиентов / заказов
- Нецелевые клиенты, много «пустых» обращений
- Несоразмерность лидогенерации и производственной мощности
- Отсутствие стратегии и планирования маркетинга
- Просели продажи при сохранении штата
- Маркетплейс / демпинг съедает маржу (ритейл, e-commerce)

## Медицина / клиники

- Перегруз администраторов, очереди, жалобы на сервис
- Низкая / неравномерная загрузка врачей
- Нет загрузки клиники, пустые окна в расписании
- Текучка среднего медперсонала
- Простой дорогого оборудования
- Ручная запись и диспетчеризация без стандартов
- Разрыв между «медициной» и «бизнес-линией» директоров

## Автосервис / услуги B2C

- Жалобы на качество ремонта / услуги
- Хаос в записи и загрузке постов
- Кассовые разрывы, сезонные провалы
- Собственник устал тушить пожары
- Нет прозрачности по марже на видах работ

## Транспорт / логистика

- Срывы сроков доставки
- Диспетчеры перегружены, нет приоритизации рейсов
- Рост издержек при падении тарифов
- Потери на простое транспорта
- Нет связки продаж (маркетинг) с планированием рейсов

## Производство (в т.ч. мебель)

- Срывы сроков по заказам
- Брак / переделки на отгрузке
- План продаж не сходится с мощностями
- Узкие места в цехах не видны управлению
- Склад и производство не синхронизированы

## Закупки / дистрибуция

- Срывы поставок, дефицит на полке
- Зависимость от 1–2 поставщиков
- Закупки не успевают за всплеском спроса
- Нет прогноза спроса для закупа
- Споры между закупкой, продажами и складом

## Интернет-магазин

- Просели конверсии и повторные продажи
- Склад и маркетинг планируют отдельно
- Высокая доля отмен / возвратов
- Нет владельца сквозной воронки «клик → отгрузка»

## Строительство / проектные компании

- Многочисленные неэффективные совещания
- Бардак в управлении проектами
- Жалобы на качество на объекте
- Срывы сроков сдачи объектов

## Как использовать в продукте

1. Подсказки в UI (выпадающий список «типовых болей» по отрасли) — опционально позже.  
2. Пакетные YAML в `cases/` — одна схема + одна боль из таблицы выше.  
3. Лимит 3 уточняющих вопроса в Streamlit — вопросы из `docs/collection_owner_questions.md`.
