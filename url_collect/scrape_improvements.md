# Эволюция парсера

## Ошибка v1–v2 (исправлено)

Собирались **не оргструктуры**: фото с `/photos/`, баннеры Tinkoff, PNG со страницы «О компании».

**Критерий (зафиксирован):** иерархическая схема с **первым руководителем** и **ресурсниками** / подчинёнными узлами.

## Правила v3 (`scraper_core.py`)

| Этап | Правило |
|------|---------|
| Страницы | Только URL/заголовки с «оргструктур», «organigram», «иерархия» и т.п.; `/about/` без этих слов — не обходим |
| Картинки | Сильные hints в path/alt; штраф `/photos/`, `logo`, `banner`, `multimedia` |
| Порог | На странице структуры score ≥ 4; иначе ≥ 9 |
| После скачивания | Pillow: min 360×280, не квадратное фото, ≥12% светлого фона |

Коллекция очищена; в `seed_urls.txt` — только осмысленные URL.
