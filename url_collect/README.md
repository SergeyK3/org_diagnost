# Коллекция URL: оргструктуры с сайтов-визиток

## Критерий отбора

См. **`ORG_STRUCTURE_CRITERION.md`**.

**Оргструктура** — иерархия, первый руководитель наверху, ресурсники / подчинённые ниже.  
Не: фото, логотипы, баннеры.

## Файлы

| Файл | Назначение |
|------|------------|
| `seed_urls.txt` | URL для парсера (добавляете вручную) |
| `org_structure_collection.json` | Коллекция URL/путей к схемам |
| `org_chart_urls.txt` | Прямые URL картинок |
| `images/` | Скачанные или вручную положенные схемы |

## Парсинг с сайтов

```bash
python scripts/scrape_visiting_cards.py --force
```

## Ручной подбор схем

Положите отобранные PNG/JPG в `url_collect/images/` и пропишите записи в `org_structure_collection.json` (или URL в `org_chart_urls.txt`).

Эталоны для диагностики остаются в `images/` проекта (галерея batch).
